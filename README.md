# Drift — إسكندرية أونلاين | مشروع جاهز لـ GitHub وVercel

الملف المضغوط يحتوي على اللعبة كاملة من النسخة التي عملنا عليها، صورة الشعار التي أرسلتها، أيقونات التثبيت، وصفحة إنشاء/دخول الغرف بواسطة Pusher.

## النشر — مهم جدًا

1. فك الضغط، وارفع **كل الملفات والمجلدات** الموجودة داخله إلى **جذر** مستودع GitHub (وليس ملف ZIP بمفرده). لازم يظهر `index.html` وبجانبه `api/` و`sw.js` و`manifest.webmanifest`.
2. اربط المستودع في Vercel عبر Add New → Project → Import. اختر Framework Preset = Other؛ واترك Root Directory على `./` لو رفعت محتويات المجلد في الجذر.
3. افتح Vercel → Project → Settings → Environment Variables وأضف القيم الأربع بالضبط (Production):
   - `PUSHER_KEY` = `07c556d525cea47a91e5`
   - `PUSHER_CLUSTER` = `eu`
   - `PUSHER_APP_ID` = خده من Pusher Dashboard → App Keys
   - `PUSHER_SECRET` = خده من Pusher Dashboard → App Keys (سرّي جدًا؛ **لا ترفعه إلى GitHub**)
4. اضغط Redeploy بعد حفظ المتغيرات.
5. افتح `https://YOUR-PROJECT.vercel.app/api/health`. لو ظهر `configured: true` فالمتغيرات موجودة فقط؛ **لا يضمن** هذا صحة المفاتيح أو نجاح الاتصال.
6. افتح رابط اللعبة، اختار «مابة أونلاين» → «إنشاء سيرفر خاص» لتجربة الـAPI وPusher. لو فشل: افتح Vercel → Logs وانسخ رسالة الخطأ (بدون أي أسرار).

## تثبيت اللعبة على الهاتف أو الكمبيوتر

- **Android/Chrome أو Windows/Chrome/Edge**: افتح اللعبة من رابط HTTPS واضغط «⬇ تثبيت Drift كتطبيق» في أول شاشة. إن لم تظهر نافذة التثبيت، استخدم قائمة المتصفح → Install app / Add to Home screen.
- **iPhone/Safari**: افتح اللعبة في Safari، زر المشاركة → إضافة إلى الشاشة الرئيسية.
- تحتوي الحزمة على `manifest.webmanifest`، أيقونتي `icon-192.png` و`icon-512.png`، و`sw.js` المفقود من بعض النسخ السابقة.
- التثبيت هو **تطبيق ويب PWA**، وليس ملف APK أصلي. وضع الأونلاين يحتاج إنترنت دائمًا.

## ملفات المشروع

- `index.html`: لعبة Drift والخريطة والجراج وواجهة الغرف وزر التثبيت.
- `api/game.js`: إنشاء/دخول الغرفة والتوثيق وإرسال تحديثات العربيات عبر Pusher.
- `api/health.js`: اختبار وجود متغيرات Pusher.
- `logo.jpg`: الشعار الذي أرسلته، مستخدم بشاشة البداية.
- `icon-192.png` و`icon-512.png`: أيقونات تثبيت التطبيق.
- `manifest.webmanifest`: تعريف تطبيق PWA.
- `sw.js`: Service Worker لكاش ملفات واجهة التطبيق، بدون تخزين طلبات API.
- `package.json`: اعتماد Pusher للسيرفر.
- `vercel.json`: إعداد منصة Vercel.
- `.env.example`: أسماء متغيرات البيئة فقط، ليست بيانات سرية صالحة.

## حدود النسخة

- أكواد الغرف 4 أرقام، وليست حماية قوية أو غرفًا دائمة.
- لم يتم اختبار الربط من حساب Pusher الخاص بك أو تجربة لاعبين على نشر حي. نجاح الخدمة يتوقف على App ID وSecret الصحيحين وإعدادات Vercel واتصال المتصفح.
- بعض مصادر اللعبة الخارجية تحتاج إنترنت حتى بعد التثبيت.
