# Drift Alexandria — Pusher + Vercel

1. ارفع محتويات هذا المجلد إلى GitHub ثم استورده كمشروع في Vercel (Framework Preset: Other).
2. من Pusher Channels Dashboard استخدم نفس التطبيق الذي تملك مفتاحه `07c556d525cea47a91e5` في cluster `eu`.
3. من Project Settings → Environment Variables أضف:
   - `PUSHER_APP_ID` = App ID الخاص بتطبيقك
   - `PUSHER_SECRET` = Secret الخاص بتطبيقك (لا تنشره أبدًا)
   - `PUSHER_KEY` = `07c556d525cea47a91e5` (اختياري لأنه معرف داخل المشروع)
   - `PUSHER_CLUSTER` = `eu` (اختياري)
4. أعد نشر المشروع، وافتح نفس رابط Vercel لدى اللاعبين.
5. افتح مابة أونلاين، أنشئ غرفة ثم شارك الكود ذا الأربع أرقام؛ الصديق يدخل بنفس الكود.

ملاحظات: لا يعمل الاتصال بمجرد فتح `index.html` من `file://`، لأن نشر حركة اللاعبين يحتاج API على Vercel. الغرف مؤقتة؛ تنتهي بخروج آخر مشترك. قد تحدث مصادفة نادرة في رمز غرفة مستخدم عند الإنشاء المتزامن. الإرسال كل نحو 150 مللي ثانية لكل لاعب؛ يمكن تقليل التردد لو عدد اللاعبين زاد. اللعبة تعرض مواقع اللاعبين فقط، وليست محاكاة فيزيائية مشتركة؛ وفي وضع الأونلاين تحتاج الأجهزة متصفحات تدعم WebGL وإنترنت. الرموز ذات 4 أرقام سهلة التخمين وليست حماية قوية، ويمكن إضافة كلمات مرور وصلاحيات للمضيف لاحقًا. يجب ضبط حدود الاستهلاك والحماية من الإغراق قبل فتح اللعبة للجمهور.
